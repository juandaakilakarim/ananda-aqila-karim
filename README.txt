PORTOFOLIO ANANDA AQILA KARIM

Cara melihat:
1. Ekstrak file ZIP.
2. Buka index.html di browser.

Sebelum dipublikasikan:
- Ganti emailkamu@example.com pada index.html dengan email aktif.
- Perbarui daftar skill sesuai kemampuan sebenarnya.
- Ganti kartu proyek contoh dengan proyek asli dan tautannya.
- Tambahkan tautan WhatsApp/GitHub/Instagram bila diperlukan.

Hosting:
Upload seluruh isi folder ini ke layanan hosting statis seperti GitHub Pages, Netlify, atau hosting web milikmu.
